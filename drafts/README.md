# drafts

`real-world-wip.tar.gz`: "실제 사례" 시리즈 작업 중 초안(글 13편 MDX·퀴즈, 지침과 배정 파일).
출처 원문 사이트에 접속할 수 없는 환경이라 작업을 멈췄고, 아직 출처 대조 검증을 하지 않았다.
빌드에 들어가지 않도록 묶어 두었다. 이어서 작업할 때 저장소 루트에서 풀어 쓴다.

```bash
tar xzf drafts/real-world-wip.tar.gz            # src/ 아래 초안 복원
tar xzf drafts/real-world-brief.tar.gz      # 지침·배정·메타데이터 파일(rw/)
```
